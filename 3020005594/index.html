nsenter

​ 这是 linux 系统中提供的一个进入当前运行 namespace 的调试工具。因为生产环境中为了减少镜像的大小，基本都是使用轻量级的初始镜像，所以并不会提供很多用于调试或信息查看的 linux 工具。因此 nsenter 允许在宿主机中进入这些 namespace，从而就可以通过宿主机的工具来进行容器调试，排障等

​ 使用 nsenter 之前，需要获取到要进入容器的进程 id，下面 d6f 这个容器 id 是 nginx 容器，本身不带有 ping 命令

​ 如果是 containerd，可以通过 ctr -n <namespace> container info <container-id> 查看容器信息，然后在 namspaces 段中看到容器对应的进程 id

​ nsenter 常用参数如下，如果这些参数后没有其他命令，就可以在进入的 namespace 执行多条命令。如果要退出 namespace，只需要执行 exit 即可。如果跟上了命令，比如上面 nsenter -t 18610 -n ping baidu.com，那么这个 ping 就只在这一次执行是在容器内：

​ 在 k8s 环境中，排查容器网络问题时可能遇到容器频繁重建，可以选择 nsenter 到 pod 中的 pause 容器排查，因为 pod 中的容器使用的是 pause 初始化的网络
